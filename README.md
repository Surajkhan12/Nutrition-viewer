
# Futuristic AI Nutrition Dashboard

## Features
- Real-time nutrition analyzer
- Hacker futuristic UI
- Matrix rain animation
- SQLite database
- Neon glowing dashboard
- Responsive design
- AJAX real-time search
- Smooth glassmorphism effects

## Setup in VS Code

### Create virtual environment
python -m venv venv

### Activate environment
venv\Scripts\activate

### Install dependencies
pip install -r requirements.txt

### Run app
python app.py

## Open Browser
http://127.0.0.1:5000

## Testing
Search:
- Apple

- Almond

## Common Fix
If database error occurs:
Delete old nutrition.db and run again.
